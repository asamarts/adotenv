# 1.6.0 plan

Status: release candidate prepared on 2026-11-22. All planned core additions,
post-merge audit fixes, focused mutation testing and documentation updates are
merged on `main`.

## Scope

`1.6.0` is an additive minor release of the lockstep crates (`adotenv`,
`adotenv-process` and `adotenv-cli`). All new enum variants are appended to
`#[non_exhaustive]` enums to preserve existing discriminants and semver
compatibility.

The release adds:

- `ParseOptions::max_lines` / `with_max_lines` and `LimitKind::Lines` across
  document, values, compact and loader entry points;
- `BomPolicy::StripAll` and full multi-BOM prefix spans from
  `Document::bom_span()`;
- `LookupIndex::unique`, matching `Document::unique` across participating,
  bare and empty keys;
- `EditOptions`, `EditError::Limit(LimitExceeded)`, `LimitKind::OutputBytes`,
  and `Document::{edit,set,remove,insert,rename}_with_options` with pre-allocation
  output byte and line budget enforcement;
- `CompactEntries`, `parse_entries_compact`, `parse_entries_compact_with` and
  `parse_entries_compact_with_options` (with `Mask` redaction support) for
  single-buffer read-only storage preserving bare declarations;
- `adotenv-compact-entries` support in `adotenv-bench`, `adotenv-xtask` and
  benchmark charts.
